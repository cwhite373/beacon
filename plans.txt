================================================================================
                    NOTEPAD CLI (NP) - PROJECT ROADMAP
================================================================================

--------------------------------------------------------------------------------
1. ARCHITECTURAL FOUNDATION (IMPLEMENT FIRST)
--------------------------------------------------------------------------------

[ ] Data Layer: Embedded SQLite Database
    - Replace raw file parsing with an embedded SQLite database (`sqlite-jdbc`).
    - Enable $O(1)$ indexed searching across logs, notes, tags, and links.
    - Schema tables required: `items`, `tags`, `item_tags`, `item_links`, `action_history`.

[ ] Execution Context: Path-Aware Execution
    - All file operations must resolve relative to `System.getProperty("user.dir")`.
    - Commands operate directly on the directory where the terminal was invoked.

[ ] State Engine: Command Pattern with History Stack
    - Design executable commands with `execute()` and `undo()` methods.
    - Log state changes to an `action_history` table to support `undo` and `redo`.


--------------------------------------------------------------------------------
2. PROJECT UPDATE LOGGING
--------------------------------------------------------------------------------

[*] log       : Append a new log entry with timestamp for current day.
                Usage: np log "Project setup completed"
[*] view      : Display all log entries recorded for the current day.
[ ] clear     : Remove all log entries for the current day.
[ ] search    : Search for specific keywords across log entries for current day.
[ ] export    : Save log entries for current day to specified formats (.txt, .csv).
[ ] filter    : Filter log entries based on criteria (e.g., date range, tags, keywords).
[*] tag       : Add category tags to log entries for retrieval and categorization.
[ ] edit      : Modify an existing log entry for the current day.
[ ] delete    : Remove a specific log entry for the current day.
[ ] sort      : Sort log entries based on criteria (date, keyword, tag).


--------------------------------------------------------------------------------
3. PERSONAL KNOWLEDGE MANAGEMENT (PKM)
--------------------------------------------------------------------------------

[ ] new --template : Create a new note initialized from a predefined template.
[ ] scratch        : Create an ephemeral scratchpad note outside main folder.
[ ] link           : Create directional/bi-directional links between notes.
[ ] tag            : Apply searchable tags to notes.


--------------------------------------------------------------------------------
4. TASK & SYSTEM UTILITIES
--------------------------------------------------------------------------------

[ ] task      : Create, manage, check off, and track todo items.
[ ] reminder  : Set time-based notifications or alerts for notes and tasks.
[ ] calendar  : View and manage scheduled calendar events.
[ ] timer     : Countdown timer for specific tasks/activities.
[ ] stopwatch : Track elapsed time spent on active tasks.


--------------------------------------------------------------------------------
5. MISCELLANEOUS & DIAGNOSTICS
--------------------------------------------------------------------------------

[ ] weather   : Display current weather conditions and forecast for a location.
[ ] easter-egg: Render a random ASCII art image from a preset collection.
[ ] stats     : View project and file diagnostics.
                Subcommands:
                - np stats notes        : Total count of notes.
                - np stats tasks        : Total count of tasks.
                - np stats logs         : Total count of log entries.
                - np stats <file_name>  : Word count, log/task count, file stats.
[ ] info      : Show detailed note/task metadata (tags, links, creation date).


--------------------------------------------------------------------------------
6. GENERAL & APPLICATION CONTROL
--------------------------------------------------------------------------------

[ ] help      : Output full list of subcommands, arguments, and usage descriptions.
[ ] version   : Print current application release version.
[ ] config    : Inspect and update application settings and default profiles.
[ ] backup    : Export full archive/backup of database, notes, tasks, and logs.
[ ] restore   : Rebuild application state from a backup file.
[ ] undo      : Revert the most recent state-changing command.
[ ] redo      : Re-apply the most recently undone command.
